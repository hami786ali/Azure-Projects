# Azure-Projects
Data analysis and cloud computing coursework completed during the Leep Talents Data Skills Bootcamp.
# About This Repository

This repository showcases Azure-related coursework completed during the Leep Talents Data Skills Bootcamp, exploring cloud computing, data analysis services and data protection considerations.

# Project: Paws & Whiskers Pet Shop

This project involved developing a proposal for a pet shop business, considering how Azure services could support its data analysis needs.

The work also explored relevant data protection requirements, including GDPR and the Data Protection Act 2018.

# Skills and Knowledge

Understanding cloud computing and Azure data analysis services

Exploring data solutions for business needs

Considering data privacy and security

Understanding GDPR and the Data Protection Act 2018

Preparing a structured business proposal

# Learning Outcomes

This project helped develop my understanding of how cloud-based services can support business data needs while considering data protection and privacy requirements.
